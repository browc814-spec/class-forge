Workflow (PS5, NBA 2K27)
  1. Forge a class here, then open Board to see the big board.
  2. In 2K: Features → Roster → Create a Draft Class → Create New Draft Class. This starts you with generated rookies; you overwrite them, because you can't create prospects from scratch.
  3. L2/R2 moves between prospects and L1/R1 filters by position. L3 = Quick Edit (position, age, height, weight). Select a player → Edit Player for ratings, potential, badges, tendencies, and appearance.
  4. Open Card mode here and tap each field as you set it, then tap Next player.
  5. Press Options to save as a new file (name + description) or update the existing one.
  6. In a MyNBA save: Scouting → Prospect Scouting → select any prospect → Load/Download Draft Class, then pick your file.
Sources: a 2K26 draft-class guide (Magic Game World) and the 2K26 MyNBA load path (Yahoo/Yardbarker). I'm assuming 2K27 uses the same menus ⚠️ (not yet verified on 2K27).
🛠️ Build a Player
  1. Fill in height, position, school, and anything else you know. Blank fields are auto.
  2. Type a backstory ("harassing defense, ball handling, low end speed…") and tap Read my description. Check the parsed chips and tap to fix them. You can also set skill levels, athletic sliders, and weaknesses directly.
  3. Build player. The Why list shows which inputs moved which ratings. Tap a rating to 🔒 lock it, then 🎲 re-roll the rest.
  4. Add to class at a pick (with Fill 1–N on, everyone from that pick down slides back one), or Save standalone to the ★ Standalone builds list. Card mode, JSON, and CSV all include him.
⚠️ Notes & limits
  • Wingspan: a 2K27 class maker reports Create-a-Player can't show wingspans above about +6". Builds here are capped at +6 ⚠️.
  • Potential fields (Min/Max Potential, Bust %, Boom %, Peak Start/End) are in the vitals area, per 2K27 class makers ⚠️. Exact labels may differ.
  • Badges come from the 2K27 list of 53 (community-verified). Tier picks use house-rule thresholds; whether the editor enforces badge requirements is unverified.
  • Tendency names are approximate. Edit tendencies before attributes, and keep "Dish to open man" at 20 or higher for non-PGs (community guide).
  • If downloading a class through the Features menu gives a generic class, load it through MyNBA Prospect Scouting instead ⚠️.
  • All players are fictional. Names are generated, so check them against real players if that matters to you.
